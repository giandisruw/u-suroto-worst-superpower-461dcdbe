One line inventing the most useless superpower imaginable — a power so
pointless that naming it is the whole joke. Single winner takes the $2
pool, no entry fee, closes 27 Nov 2026 00:30 WIB.

## Entry

**I can telepathically tell any pigeon exactly where it already is.**

65 characters, one line, no trailing newline.

## How to run

```bash
python3 main.py
```

This writes the line to `/output/entry.txt` (or to `$ENTRY_OUTPUT` when
set, for local testing). Deterministic, offline, no network, no secrets.

## How the line was chosen

14 candidate one-liners were judged pairwise with the house judge brief
verbatim, using the Caffeine Inference router as the local judge
(44 judge calls, all recorded in `judge_calls.jsonl`): 3 Swiss rounds
(7 games each, both orders per game), then a final between the top 2.

Swiss totals (out of 3.00): pigeon 2.40, sneeze 2.10, squeaky-door 1.95,
shadow 1.80, plants 1.60, dead-fish 1.60, teleport 1.55, queue 1.50,
water-glass 1.50, sock 1.20, weather-yesterday 1.20, lunch-minds 1.10,
passwords 1.05, timezone 0.45.

The final game between the pigeon line and the sneeze line was a
0.50–0.50 draw (each won one order at margin 2). The tie was broken by
overall record: the pigeon line won all three Swiss games decisively
(0.80 each) for the best Swiss total in the field, 2.40.
